Getting Started

From zero to a fully moderated server in under two minutes.

1

Invite stry

Click Add to Discord anywhere on this page, pick your server, and approve the permission prompt. You need the Manage Server permission to invite bots.

2

Verify permissions

Make sure stry's role is above the roles it needs to manage (drag it in Server Settings → Roles), and that it can view/send in your channels.

3

Run the setup command

Run the command below in any channel stry can see. It walks you through moderation, leveling and logging setup.

example 
/setup
💡 Tip

Try /help at any time to see every command stry offers, grouped by category.

Commands

stry uses Discord slash commands. Type / in any channel to browse them all — or search the reference below.

No commands found. Try a different search.

🛡️ Moderation

/ban user · reason · delete_days Permanently ban a member and optionally wipe their recent messages. Ban Members
/timeout user · duration · reason Temporarily mute a member — from 60 seconds to 28 days. Moderate Members
/kick user · reason Remove a member from the server. They can rejoin with a new invite. Kick Members
/warn user · reason Issue a tracked warning. Automate escalations at warning thresholds. Manage Messages
/purge amount · user? · matches? Bulk delete up to 100 messages, optionally filtered by user or keyword. Manage Messages
/slowmode channel · seconds Set a per-channel send cooldown to slow down spam bursts. Manage Channels
/lock channel · reason Instantly lock a channel (or the whole server during a raid). Manage Channels
/case view · id | list · user Inspect the moderation history of any case or member. Moderate Members

🧰 Utility

/help command? Browse every command, or get detailed usage for a specific one. Everyone
/ping Check stry's websocket latency and uptime. Everyone
/serverinfo Detailed stats about the current server — members, boosts, channels, roles. Everyone
/userinfo user? Whois any member — join date, roles, badges and more. Everyone
/poll question · options · anonymous? Create instant polls with up to 10 options and live results. Everyone
/remind time · text Set a personal reminder — stry will DM you when time's up. Everyone
/embed json Post a rich embed from raw JSON. Full control over color, fields and images. Manage Messages

📈 Levels

/rank user? Show a beautiful animated rank card for you or another member. Everyone
/leaderboard scope? Top 10 most active members — server-wide or per-channel. Everyone
/givexp user · amount Grant XP manually — great for events and giveaways. Manage Guild
/levelrole add · level · role Automatically hand out roles when members reach a level. Manage Roles

🎮 Fun

/8ball question Ask the magic 8-ball anything. It knows. Everyone
/dice sides · count Roll dice — from a coin-flip d2 to a chaotic d100. Everyone
/meme Fresh memes, delivered hot from the oven. Everyone
/ship user1 · user2 Calculate the compatibility of two members. Science™. Everyone
💡 Good to know

Reference

Configuration

Tailor stry to your community. All settings are per-server and managed with commands.

Welcome & goodbye messages

Greet new members with a customizable embed — support variables for username, member count and more.

example 
/config welcome channel:#welcome message:"Welcome {user} to **{server}**! You are member #{count}."

Auto-mod filters

Automatically delete invites, links, spam, caps and banned words — and punish repeat offenders.

example 
/automod add filter:invites action:delete
/automod add filter:bad_words action:timeout duration:10m
/automod antiraid on

Logging

Send moderation actions, message deletions, member joins/leaves and role changes to a private log channel.

example 
/config log channel:#mod-logs events:all
Reference

Permissions

stry respects Discord's native permissions. By default, a command requires the same permission it acts with.

LevelWhoCan do
0 · Everyone All members Fun, utility and level commands
1 · Moderator Members with a moderation permission (Kick / Ban / Timeout / Manage Messages) All moderation commands, automod, purge, cases
2 · Administrator Members with Administrator or Manage Guild Full configuration, level roles, command overrides
3 · Server Owner The server owner Everything, plus resetting all stry settings
💡 Best practice

Give stry only the permissions it needs. Every command above lists the minimum permission required.

FAQ

Quick answers to the questions we get most.

Is stry free?

Yes — every feature on this page is free forever. No paywalled moderation, no premium-only commands.

How do I change stry's permissions in my server?

Head to Server Settings → Roles, drag stry's role above the members it should manage, then re-invite it with the permissions listed in Getting Started.

The bot isn't responding — what do I do?

Run /ping first. If it responds, check channel-level command overrides in /config. If it doesn't, check our status channel in the support server — we post every incident there.

Can I use stry in multiple servers?

Absolutely. Invite it to as many servers as you like — settings are stored per server.

How do I report a bug or security issue?

Open a ticket in the support server. Responsible disclosure of security bugs is always appreciated — we won't blacklist good-faith reports.
